# Customer Delinquency Risk Analysis Dashboard

## 📌 Project Overview

This project focuses on analyzing customer delinquency risk using Power BI. The dashboard provides insights into customer behavior, payment patterns, and risk indicators to help financial institutions identify customers who are likely to become delinquent and take proactive measures.

## 🎯 Objectives

- Analyze customer financial and behavioral data.
- Identify high-risk customers.
- Monitor delinquency trends.
- Support data-driven decision-making.
- Improve risk management strategies.

## 🛠️ Tools & Technologies

- Power BI
- DAX (Data Analysis Expressions)
- Data Modeling
- Excel / CSV Dataset
- Data Visualization

## 📊 Dashboard Features

### Executive Summary
- Total Customers
- High-Risk Customers
- Delinquency Rate
- Average Risk Score

### Risk Analysis
- Customer Risk Segmentation
- Delinquency Distribution
- Risk Score Analysis

### Customer Insights
- Customer Demographics
- Payment Behavior Analysis
- Credit Utilization Patterns

### Interactive Filters
- Customer Segment
- Risk Category
- Region
- Time Period


## 📈 Key Insights

- Identified customer segments with the highest delinquency risk.
- Analyzed payment behavior patterns associated with delinquency.
- Highlighted trends in customer risk scores.
- Provided actionable insights for risk mitigation.

## 🚀 How to Use

1. Download the `.pbix` file.
2. Open it using Power BI Desktop.
3. Refresh the dataset if required.
4. Explore the interactive dashboards and visualizations.

## 💡 Business Impact

This dashboard enables organizations to:

- Reduce financial risk.
- Improve customer monitoring.
- Identify potential delinquency early.
- Enhance decision-making through data-driven insights.
